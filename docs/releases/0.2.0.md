# AGENTS 0.2.0 preview

- Smoother continuously animated holographic face, twelve isolated preview states, real agent-state indicators and measured rendering diagnostics.
- In-app authenticated GitHub update checks, bounded downloads, native installation approval and preserved Windows security prompts. Updates require signed build provenance, compatible metadata and matching installer bytes.

This is an unsigned Windows preview. Sigstore authenticates the GitHub build and is not an Authenticode certificate. Cloud fixtures and hosted Windows checks do not establish SmartScreen acceptance, laptop GPU performance or real Notepad input control. No live paid AI testing is included.
