# AGENTS 0.2.1 preview candidate

- Persistent, redacted installation logs identify each staging operation and public package-relative extraction failures. Native directory operations report their Windows error codes.
- Staging promotion has bounded retries for temporary directory access/sharing locks. Persistent failures leave the previous payload, shortcuts and personal data intact; cleanup deletes only build-owned staged files.
- Explicit package extraction, required layout checks, collision rejection and recovery paths preserve the existing installer integrity and per-user security boundaries.
- Windows acceptance now runs the authenticated published 0.2.0 installer followed by this candidate at a path containing spaces, with injected permission/lock failures and byte-preservation checks.

This is an unsigned Windows preview. No Windows protection is disabled. Hosted acceptance does not establish the cause of a laptop-specific failure, SmartScreen acceptance or real desktop control. Publication requires separate owner approval after the candidate passes verification.
