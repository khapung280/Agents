# AGENTS 0.2.2 repair candidate

- Detects a missing, inaccessible or unusable registered executable before installation changes. It no longer invents a previous-version recovery target from stale registration.
- When the registered executable is missing, offers an explicit fresh per-user installation at `%LOCALAPPDATA%\Programs\Ultimate Agents Both`. The original directory remains intact; existing data, memories, settings and approvals keep their existing location. Recovery refuses an occupied destination and preserves the version floor.
- Promotion failures retain the exact native error plus redacted source, parent and target attributes and nonmutating access probes. Access denial is reported without claiming an unproven cause or changing security settings.
- Windows acceptance reproduces missing executables, empty `versions`, stale shortcuts and a path containing spaces. An isolated permission fixture allows root folder creation while denying promotion, then tests explicitly selected recovery without changing the original restriction.

This is an unsigned Windows preview. The installer preserves normal Windows security prompts. Hosted tests do not identify the laptop-specific reason for error 5, establish why an earlier executable disappeared, or verify real desktop control. Publication requires separate owner approval after Windows verification.
